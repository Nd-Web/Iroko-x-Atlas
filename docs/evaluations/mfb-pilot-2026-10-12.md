## Prioritised gaps

1. Fix multi-intent routing before adding more documents: 'who owns it internally' must not swallow a circular-inventory request, and 'pending review' in transaction notes must not swallow a drafting request. Regressions: Q3 and Q8.
2. Build the capital answer from primary instruments with an explicit later-amendment check, preserve uncertainty, add a clearly conditional paid-up comparison, and render title/reference/date/page plus an official or authorised durable document link. A copied publication is not proof it remains the latest rule.
3. Add a source-authority conflict check. Q12 shows why an exact quotation from regulator guidance still needs checking against the underlying Act; flag conflicting section references instead of silently repeating them.
4. Make temporal and coverage questions actual inventory/calendar tasks. Resolve relative dates, collect primary circulars by issue date and scope, keep event-triggered reports separate, and label proposed owners. Never equate an empty graph or bounded web search with exhaustive coverage.
5. Replace generic missing-information text with the actual missing input. Preserve the unit licence already supplied; ask for the exact KYC discrepancy, sanction notice or unidentified circular; do not say 'no user input needed' and then ask the user to identify missing evidence. Keep capital-specific warnings out of unrelated deadline questions.
6. Support audit follow-ups from stored records: show source-to-conclusion rationale, timestamps, actual stage attribution and model/provider metadata, rather than running a new investigation and calling its trace the explanation of the old answer.
7. Improve bounded public-source discovery and latency. Several runs record zero successful Bright Data searches and unavailable PDFs. Name the failed checks, distinguish cached/indexed primary evidence from failed live re-fetches, and retain the useful parts of an answer without pretending live coverage is complete.
